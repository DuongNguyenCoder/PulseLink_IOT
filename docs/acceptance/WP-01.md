# WP-01 acceptance record

This document is the evidence template for baseline and build/test workflow
changes. A check is `PASS` only when its command actually ran and returned exit
code 0. `BLOCKED` is not `PASS`.

## Reproduction context

- Repository: `D:\project-PulseLink`
- Backend working directory: `server/api`
- Firmware working directory: `firmware/esp32`
- Firmware target: `esp32s3`
- Required ESP-IDF: `v5.5.5`
- Hardware operations: not part of WP-01; no flash, erase, monitor, reset or
  COM-port operation is permitted.

## Standard commands

From the repository root:

```powershell
.\scripts\Invoke-BackendBaseline.ps1
.\scripts\Invoke-FirmwareBuild.ps1
```

The backend wrapper runs typecheck, build, tests and Prisma validation. It also
reports lint as `NOT CONFIGURED` because the current package has no lint script;
it exits with code 2 in that case. Do not add a fake lint check just to make the
report green.

The firmware wrapper requires an ESP-IDF PowerShell with `idf.py` available and
checks that the reported version is exactly v5.5.5 before running `idf.py build`.

build, tests, Prisma validation and firmware compilation. Hardware-required
